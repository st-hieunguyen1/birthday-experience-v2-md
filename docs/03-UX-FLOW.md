# UX Flow — V2

## Primary Flow

Landing
→ Enter
→ Character
→ Little Things
→ Stories
→ People Around You
→ Explore Nodes
→ All Nodes Discovered
→ Everyone Is Here
→ Final Wishes
→ Happy Birthday

## UX Principle

The user should feel that they are discovering something rather than completing a checklist.

Avoid making the experience feel like:

> "You must open 15 cards to finish."

Instead communicate:

> "There is more here. Look around."

## Interaction Feedback

Every interaction should produce meaningful feedback.

### Hover / Touch Preview

- node grows slightly
- glow increases
- person's name appears
- connection line reacts

### Open

1. constellation slows;
2. selected node becomes dominant;
3. camera moves toward it;
4. other nodes become quieter;
5. memory window opens.

### Close

The memory returns to the constellation.

The node remains visibly discovered.

## Node States

LOCKED
→ AVAILABLE
→ VIEWED

No harsh gamification is necessary.

A viewed node may simply become:

- brighter
- connected
- filled
- marked with a subtle symbol

## Progress

Optional:

```text
07 / 18
```

If used, keep it subtle.

The goal is discovery, not task completion.

## Completion

When all required nodes have been viewed:

```text
EVERYONE IS HERE.
```

Then begin the finale.

## Important

Do not force N to read long messages.

Long content should be visually broken into:

- short paragraphs
- quotes
- images
- video
- expandable sections

The emotional experience should remain light enough to enjoy.
