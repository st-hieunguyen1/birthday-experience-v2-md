# Media Guidelines — V2

## Creative Principle

Media should preserve memories without making N's appearance the subject.

The strongest content is not necessarily the most beautiful photograph.

A blurry photo with a meaningful story may be more valuable than a perfect portrait.

## Preferred Media

Good:

- candid moments
- group moments
- work memories
- travel memories
- meals
- funny moments
- screenshots of harmless inside jokes
- short videos
- contributor avatars
- objects or places connected to a memory

Use caution with:

- old portraits of N
- highly edited beauty photos
- photos chosen primarily to show appearance

Avoid unless explicitly requested by N:

- accident photos
- hospital photos
- medical images
- photos that emphasize injuries
- before/after comparisons
- images intended to compare facial appearance

## Image

Preferred:

- WebP
- AVIF

Recommended maximum:

2000–2400px long edge.

## Avatar

Recommended:

800 × 800

Aspect ratio:

1:1

## Memory Images

Recommended:

1600–2400px long edge.

## Video

Preferred:

- MP4
- WebM where appropriate

Recommended:

- H.264
- 720p or 1080p
- 5–30 seconds

Avoid unnecessary 4K footage.

## Audio

If using voice:

- normalize volume
- remove excessive silence
- provide playback controls
- do not autoplay with sound

## File Naming

```text
person-01-avatar.webp
person-01-memory-01.webp
person-01-memory-02.webp
person-01-video-01.mp4
```

Avoid:

```text
IMG_839201.jpg
VID_20260421.mp4
final_final_2.mp4
```

## Optimization

Original
→ Crop
→ Resize
→ Compress
→ Convert
→ Validate
→ Deploy

Never make the website depend on enormous original files.
